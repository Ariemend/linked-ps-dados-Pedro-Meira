---Como rodar o projeto---
Primeiro, é necessario que você tenha todas as bibliotecas instaladas (além de python, claro), para isso, basta rodar os comandos:

pip install pandas
pip install streamlit
pip install plotly

Feito isso, acesse a pasta do projeto pelo terminal e rode o seguinte comando:

python -m streamlit run main.py

O projeto deve abrir dentro do seu navegador.
